# Missing-host Desktop dependency acquisition

`desktop_dependency_capture.py` is a finite, read-only wrapper used only by the
four-host `webview-desktop-security-regressions` workflow. [Preparation evidence](evidence/current-platform-recovery-20261101/desktop-missing-host-capture-prepared081/README.md)
is synthetic/source verification, **not graph/native/security acceptance**.

## Flow and controls

1. Admit exact profile/slot/suite/WebView module/focus and actual clean runtime
   source/host; refuse existing output, linked/substituted paths and foreign hosts.
2. Hold the full configured input map plus workflow/archived collector hashes.
3. Exclusively copy the byte-pinned original collectors to owned private init
   files; acquire runtime24 then compile/test48 exactly once, serially.
4. The existing owned process-group executor enforces600 seconds/invocation and
   an8GiB **disk** reserve. Failed first graph does not retry or erase it; safe
   independent second graph and native results may still run, leaving the job red.
5. Require exact24 project identities/72 total configurations, complete Booleans,
   no unresolved/duplicate/foreign rows, `allComponents` artifactless coordinates,
   artifact facts, fresh unique task/coordinate markers and exact original copies.
6. Check final full inputs/runtime/revision, preserve originals/private raw logs,
   remove only exact owned init files, and refuse unowned cleanup substitutions.
   JSON-only flat files remain within the existing upload allowlist; no packages,
   native binaries, raw logs or private init paths are exported.

Runtime graph/module artifacts are observed bytes, not remote provenance/trust.
Input maps are before/after, not a continuous sandbox attestation. Windows Unix
mode requests are not ACL proof. Capture success is not advisory/native/consumer/
ABI/security/legal/readiness acceptance. Reuse the accepted Linux142 queries;
review actual new-host unions/classifiers and query only genuinely new coordinates.
No publication, Pages, deployment, release or main integration is authorized by
this helper. Heavy workflows remain globally bounded to two jobs.
